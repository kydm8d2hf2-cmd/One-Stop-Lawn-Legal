# One Stop Lawn — Legal

Public legal pages for the One Stop Lawn mobile and web app.

- **Privacy Policy:** [privacy.html](https://kydm8d2hf2-cmd.github.io/One-Stop-Lawn-Legal/privacy.html)
- **Terms of Service:** [terms.html](https://kydm8d2hf2-cmd.github.io/One-Stop-Lawn-Legal/terms.html)

## How to update

1. Edit the corresponding `.md` file (`privacy.md` or `terms.md`)
2. Update the matching `.html` file with the same changes
3. Update the **Effective Date** at the top of both
4. Commit

The `.md` files are the source-of-truth for editing; the `.html` files are what visitors actually see.
